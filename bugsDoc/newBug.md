# Bug report: Login button not working

## Description

- After entering valid login credentials and clicking the Login button, the form does not submit and nothing happens.

## Steps to Reproduce

1. Go to the login page.
2. Enter username and password.
3. Click the "Login" button.

## Expected Result

- User should be logged in and redirected to the home dashboard.

## Actual Result

- Nothing happens, and the page stays on the login screen.

## Environment

- **Browser:** Google Chrome & Microsoft Edge
